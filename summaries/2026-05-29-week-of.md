# Week of 2026-05-29
_7 lessons covered_

> **The thread:** This week Claude went from a tool you prompt to a system that reacts and delegates on its own — hooks make Claude self-checking, subagents make it parallel. Together they're the foundation for voice agents that can test themselves and research multiple APIs without you babysitting every step.

## Lessons this week

### 1. Hooks — 2026-05-23
- **What it is:** Shell commands in `settings.json` that fire automatically before/after tool calls or when Claude finishes a turn.
- **What he can now do:** Add a `Stop` hook to auto-run a smoke test after every Claude session, so broken voice agent configs are caught before handoff.

### 2. PreToolUse Hook — 2026-05-24
- **What it is:** A gatekeeper hook that can block a tool call entirely if your script exits non-zero.
- **What he can now do:** Write a one-time rule (e.g., block `rm -rf`) that silently protects staging databases without re-stating it every session.

### 3. PostToolUse Hook — 2026-05-25
- **What it is:** A reactive hook that runs after a tool completes — good for logging or auto-formatting, but can't undo what already happened.
- **What he can now do:** Log every file Claude edits to a change diary, giving stakeholders a clean audit trail of every prompt iteration.

### 4. Stop Hook — 2026-05-26
- **What it is:** A hook that fires at the end of Claude's whole turn; if it fails, Claude reads the error and self-corrects before handing back control.
- **What he can now do:** Wire up `npm test` or `pytest` as a Stop hook so Claude never returns a broken agent flow without at least trying to fix it.

### 5. Subagents — 2026-05-27
- **What it is:** Fresh Claude instances Claude spawns to handle independent tasks in parallel, each with a clean context window.
- **What he can now do:** Ask Claude to research Twilio Voice and Amazon Polly simultaneously and get a comparison in half the time.

### 6. Built-in Subagents — 2026-05-28
- **What it is:** Three ready-made subagent types: `Explore` (read-only file scout), `Plan` (architect, no code written), and `general-purpose` (everything else).
- **What he can now do:** Use `Explore` to find every file referencing a wake word, or `Plan` to get a numbered design for a new voice intent before any engineer touches code.

### 7. Custom Subagents — 2026-05-29
- **What it is:** A markdown file in `.claude/agents/` with a name, description, and system prompt that creates a reusable specialist Claude can delegate to by name.
- **What he can now do:** Write a `transcript-reviewer` agent once with Theatro's grading rubric baked in, then invoke it on any transcript without re-explaining the criteria.

## Suggested next steps
- **Build the transcript-reviewer agent now.** Create `.claude/agents/transcript-reviewer.md` with your team's intent-coverage rubric. Run it on three real transcripts this week and see if it surfaces the same gaps a human reviewer would.
- **Add a Stop hook to your voice agent repo.** Even a simple `echo "session ended" >> claude-log.txt` will prove the wiring works; then swap it for a real lint or test command.
- **Combine both:** Ask Claude (via a `general-purpose` subagent) to research one new voice API while your `transcript-reviewer` agent reviews last week's transcripts in parallel — that's the full pattern in action.

## Quick reference card

| Topic | Command/Idea | When to use it |
|---|---|---|
| Hooks | `"hooks"` key in `.claude/settings.json` | Automate any reaction to Claude's actions |
| PreToolUse | Exit non-zero to block a tool call | Guard dangerous commands (destructive deletes, prod writes) |
| PostToolUse | Runs after tool; reads `CLAUDE_TOOL_INPUT_FILE_PATH` | Log changes, auto-format, notify |
| Stop Hook | Fires at end of turn; failure = Claude self-corrects | Auto-test after every session |
| Subagents | `Agent` tool, parallel instances | Parallel research or large tasks with many files |
| Explore agent | `Use the Explore agent to find...` | Fast read-only code search, no edits |
| Plan agent | `Use the Plan agent to sketch...` | Architecture design before coding starts |
| Custom subagent | `.claude/agents/your-name.md` with frontmatter | Reusable specialist with your rubric/persona baked in |
| Custom agent routing | `description:` field in frontmatter | Write it as a rule so Claude auto-routes correctly |
| Custom agent model | `model: claude-haiku-4-5-20251001` in frontmatter | Use cheaper model for routine grading/formatting tasks |
