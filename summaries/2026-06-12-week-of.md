# Week of 2026-06-12
_7 lessons covered_

> **The thread:** This week Claude Code left the chat box — every lesson was about wiring it into the tools and workflows you already live in: your terminal, your scripts, your IDE, GitHub, and the live web. Claude stops being a conversation partner and starts being a component.

## Lessons this week

### 1. The Bash Tool — 2026-06-06
- **What it is:** Claude can run any terminal command on your machine and read the output
- **What he can now do:** Ask Claude to run a transcript parser, grep logs, or check an API mid-conversation — no tab-switching required

### 2. Parallel Tool Calls — 2026-06-07
- **What it is:** Claude fires multiple independent actions simultaneously instead of one at a time
- **What he can now do:** Ask Claude to read several config files or run multiple searches in a single message and get results faster

### 3. Image Input — 2026-06-08
- **What it is:** Paste a screenshot directly into Claude Code and Claude reasons about what's on screen
- **What he can now do:** Drop an agent dashboard screenshot or error UI into the chat instead of describing it in words

### 4. Web Search and WebFetch — 2026-06-09
- **What it is:** Two tools that pull live internet data mid-session — search results or a full URL's content
- **What he can now do:** Ask Claude to fetch a vendor's latest changelog before writing an integration, bypassing stale training-data answers

### 5. Headless Mode — 2026-06-10
- **What it is:** Run Claude Code non-interactively from a script with `-p`, piping input and output
- **What he can now do:** Loop Claude over a folder of call transcripts and run the same quality check on all of them without a chat window

### 6. GitHub Actions Integration — 2026-06-11
- **What it is:** The `claude-code-action` GitHub Action lets anyone type `@claude` in a PR comment to trigger Claude on your repo
- **What he can now do:** Spot a bug in a voice webhook during PR review, comment `@claude fix this`, and get a committed fix — no terminal

### 7. IDE Extensions — 2026-06-12
- **What it is:** Official VS Code and JetBrains extensions embed Claude Code in the editor sidebar with inline diff review
- **What he can now do:** Highlight confusing agent code and ask Claude about it without leaving the file — no window-switching

## Suggested next steps
- **Script a batch transcript review:** Use headless mode (`cat transcript.txt | claude -p "..."`) on 5–10 real Theatro call transcripts this weekend. See how fast you can get quality signal at scale without eng involvement.
- **Add the GitHub Action to one repo:** Drop the `claude.yml` workflow into your voice agent repo, add the API key secret, and try `@claude explain this function` on an open PR. Gets the whole team using Claude in review without onboarding anyone.
- **Paste the next error screenshot:** Next time you hit an unexpected agent response or a broken dashboard, screenshot it and paste into Claude Code before reaching for Slack. Trains the habit of "show, don't describe."
