# Week of 2026-05-22
_6 lessons covered_

> **The thread:** Every lesson this week was about making Claude Code *yours* — five of six topics covered ways to configure its behavior, context, and autonomy so it works like a trained teammate instead of a blank-slate chatbot.

## Lessons this week

### 1. Slash Commands — 2026-05-18
- **What it is:** Built-in one-word shortcuts (`/help`, `/clear`, `/review`) for common actions
- **What he can now do:** Control Claude Code without typing a prompt — use `/help` to discover every shortcut instantly

### 2. Custom Slash Commands — 2026-05-18
- **What it is:** A `.md` file in `.claude/commands/` becomes a reusable prompt triggered by `/command-name`
- **What he can now do:** Turn repeated agent-testing prompts (transcript reviews, edge-case checks) into one-keystroke commands

### 3. CLAUDE.md Files — 2026-05-19
- **What it is:** A standing briefing file Claude reads automatically at the start of every session
- **What he can now do:** Write project context once (voice constraints, folder structure, what Theatro agents do) and never re-explain it again

### 4. Plan Mode — 2026-05-20
- **What it is:** A read-only mode (`Shift+Tab` twice) where Claude proposes changes before making them
- **What he can now do:** Review Claude's intent before any file is touched — essential for iterating safely on agent prompt logic

### 5. Permission Modes — 2026-05-21
- **What it is:** A dial from "ask every time" to "do everything automatically" (`--dangerously-skip-permissions`)
- **What he can now do:** Run fast throwaway prototypes in auto-accept mode, then switch back to ask-mode for production agent code

### 6. settings.json — 2026-05-22
- **What it is:** Global (`~/.claude/settings.json`) and per-project (`.claude/settings.json`) config files for persistent preferences
- **What he can now do:** Commit a project settings file so every engineer on the Theatro team gets identical Claude behavior — same auto-approved tools, same model

## Suggested next steps
- **Wire up a `CLAUDE.md` for your voice agent repo** — paste in the 15-word response constraint, the `/transcripts` path, and two or three things Claude should never do. One session of investment, permanent payoff.
- **Create a `/review-transcripts` custom command** that prompts Claude to scan your latest test transcripts for missed intents or broken flows. Run it after every agent test cycle.
- **Commit a `.claude/settings.json`** that pre-approves `git log` and `cat` on your transcript files — you'll stop seeing permission prompts for the reads you do every single session.
