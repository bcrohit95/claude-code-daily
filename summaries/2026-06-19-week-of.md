# Week of 2026-06-19
_7 lessons covered_

> **The thread:** This week closed the loop from UI to API — shortcuts and status lines cut session friction, /init and /review speed up project work, and model selection plus prompt caching cut the bill. Every lesson was a different dial on the same question: how do you run Claude faster and cheaper?

## Lessons this week

### 1. Keyboard Shortcuts Worth Memorizing — 2026-06-13
- **What it is:** Five keystrokes that handle the most common Claude Code friction — stopping runaway responses, writing multi-line prompts, and recalling history.
- **What he can now do:** Press `Escape` to stop mid-generation and `Shift+Enter` to write structured prompts without accidentally submitting them.

### 2. Status Line — 2026-06-14
- **What it is:** The info bar above the input prompt, customizable via `settings.json` to show model, token count, cost, or git branch.
- **What he can now do:** Pin `model tokens` to the status line so he always knows what's running and roughly what it costs — before a session surprises him.

### 3. Output Styles — 2026-06-15
- **What it is:** Claude's verbosity is a dial — control it inline ("in one sentence:"), set a default in CLAUDE.md, or toggle tool-call display with `/verbose`.
- **What he can now do:** Add one line to CLAUDE.md to make every session lean by default, and override per-turn when he needs depth.

### 4. /init — Generating a CLAUDE.md for an Existing Project — 2026-06-16
- **What it is:** A slash command that reads the repo and drafts a `CLAUDE.md` project briefing automatically.
- **What he can now do:** Run `/init` in any repo to get a real first draft in under a minute instead of staring at a blank file.

### 5. /review — Using Claude to Review a Pull Request — 2026-06-17
- **What it is:** A built-in skill that reads the current branch's diff and produces a structured code review without needing an engineer.
- **What he can now do:** Run `/review` before asking a teammate "does this look right?" — catching obvious mistakes before they cost social capital.

### 6. Model Selection — When to Use Opus vs Sonnet vs Haiku — 2026-06-18
- **What it is:** Claude has three tiers (Haiku / Sonnet / Opus) at different cost and capability levels; Sonnet is the default.
- **What he can now do:** Drop to Haiku for quick prompt spot-checks and reach for Opus only for complex agent design or long-doc analysis.

### 7. Prompt Caching — What It Is and How It Saves Money — 2026-06-19
- **What it is:** Mark stable parts of your system prompt with `cache_control`; Claude reuses them at ~10% of normal cost on subsequent calls.
- **What he can now do:** Add `cache_control` to his voice agent's system prompt and verify it's working via `cache_read_input_tokens` in the API response.

## Suggested next steps

|---|---|---|
| Keyboard shortcuts | `Escape` to stop, `Shift+Enter` for new line, `↑` for history | Every session |

| Output verbosity | `"in one sentence:"` prefix, `/verbose` for tool calls | Quick checks vs. debugging |
