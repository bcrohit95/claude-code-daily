# Week of 2026-06-26
_7 lessons covered_

> **The thread:** This week crossed the line from "Claude as a tool" to "Claude as the engine inside a product" — cost controls and safe experimentation in the first half, then the actual code patterns for building and debugging a real voice agent in the second. The curriculum ended; the stack you can ship with didn't.

## Lessons this week

### 1. Prompt Caching — 2026-06-19
- **What it is:** Mark stable parts of your system prompt with `cache_control`; Claude reuses them at ~10% of normal cost on subsequent calls.
- **What he can now do:** Cut API costs by up to 90% on repeated voice agent calls by caching the system prompt and verifying savings via `cache_read_input_tokens`.

### 2. Cost and Rate Limits — 2026-06-20
- **What it is:** Practical habits — spend caps in Console, `/model` switching, and `/compact` — that keep prototype costs from compounding unexpectedly.
- **What he can now do:** Set a hard monthly spend limit and switch to Haiku for routing/retrieval steps, reserving Opus only for complex reasoning.

### 3. Worktrees — 2026-06-21
- **What it is:** A git worktree checks out a branch into a second folder so Claude can experiment freely while the stable version stays untouched.
- **What he can now do:** Give Claude its own isolated sandbox for risky experiments with `git worktree add`, then discard or merge when done.

### 4. Git Workflows with Claude — 2026-06-22
- **What it is:** Claude handles branches, commits, and pull requests through plain English — no terminal switching required.
- **What he can now do:** Say "create a branch and open a draft PR" mid-session and get a PR link back without touching git commands.

### 5. Debugging Claude's Mistakes — 2026-06-23
- **What it is:** Re-prompting strategies matched to failure types — misunderstood goal, ignored constraint, off-track mid-task, or fully lost context.
- **What he can now do:** Diagnose *why* Claude went wrong and apply the right fix (targeted correction, constraint re-statement, or `/clear`) instead of just retrying.

### 6. The Claude Agent SDK — 2026-06-24
- **What it is:** Anthropic's Python/TypeScript SDK with a `tool_runner` that automatically loops between Claude and your functions until the task completes.
- **What he can now do:** Build a voice agent that calls backend functions (shift lookup, inventory check) by writing a decorated function and one `tool_runner()` call — no manual loop.

### 7. Putting It All Together — 2026-06-25
- **What it is:** A four-file starter kit (CLAUDE.md, settings.json, custom slash command, custom subagent) that wires the curriculum into a working voice AI setup.
- **What he can now do:** Bootstrap any new voice AI project with a context file, a `/analyze` command for transcripts, and a PM-assistant subagent that already knows his product vocabulary.
