## Lessons this week

### 1. Slash Commands — [2026-05-18]
- **What it is:** Built-in shortcuts typed directly in the chat prompt (e.g. `/help`, `/clear`, `/review`) that trigger Claude Code actions without a written request.
- **What he can now do:** Navigate Claude Code's core functions in two keystrokes — reset context, review code, open settings, or get help — without composing a prompt each time.

## Suggested next steps
- Open Claude Code in your terminal, type `/help`, and scan the full list — look for anything relevant to the voice AI work at Theatro (e.g. `/review` for code reviews, `/init` to document a prototype repo).
- Next time your Claude Code context feels stale or confused mid-session, reach for `/clear` instead of starting a new window — it resets what Claude sees without touching your files.
- When you add a new project, run `/init` to auto-generate a `CLAUDE.md` — that file becomes the memory Claude reads at the start of every session, which matters a lot for multi-session agent work.
