# Week of 2026-06-05
_8 lessons covered_

> **The thread:** This week turned Claude from a session-by-session assistant into a persistent, connected agent — one that knows who you are, reaches live data, runs your playbooks automatically, and shows its work in real time.

## Lessons this week

### 1. Custom Subagents — 2026-05-29
- **What it is:** A markdown file in `.claude/agents/` that gives Claude a specialist persona and standing instructions
- **What he can now do:** Create a `transcript-reviewer` agent that applies his grading rubric to every voice session without re-explaining the rules

### 2. Skills — 2026-05-30
- **What it is:** Pre-packaged slash-command playbooks that run a full multi-step workflow in one command
- **What he can now do:** Run `/deep-research` or `/code-review` to kick off a structured workflow with no extra prompting

### 3. Creating a Custom Skill — 2026-05-31
- **What it is:** A markdown file in `.claude/skills/` that becomes a project-specific slash command
- **What he can now do:** Write `/transcript-review` once and run his standard review workflow in a single command, every session

### 4. MCP (Model Context Protocol) — 2026-06-01
- **What it is:** An open standard that lets Claude connect to external tools — databases, APIs, files
- **What he can now do:** Understand the architecture behind giving Claude live access to shift schedules, ticketing systems, or product lookups

### 5. Connecting an MCP Server — 2026-06-02
- **What it is:** A JSON config block in `settings.json` that wires a real tool into Claude's toolset
- **What he can now do:** Point Claude at his local transcripts folder or GitHub repo with one config change — no copy-pasting

### 6. Memory Tool — 2026-06-03
- **What it is:** A file-based memory system that persists preferences and project context across sessions
- **What he can now do:** Say `Remember: voice responses under 150 words` once and have that constraint active in every future session

### 7. Tasks — 2026-06-04
- **What it is:** Claude's built-in live checklist that tracks each step of a multi-step job
- **What he can now do:** Watch Claude's progress in real time during complex agent setup — no more "what is it doing?"

### 8. The Read, Edit, and Write Tools — 2026-06-05
- **What it is:** Three distinct file tools with different risk profiles: Read (safe), Edit (surgical), Write (full replace)
- **What he can now do:** Say "update" instead of "rewrite" to keep Claude from replacing an entire config file when only one line needs to change

## Suggested next steps
- **Build the transcript-reviewer subagent now.** Create `.claude/agents/transcript-reviewer.md` with your rubric (flag turns over 2 sentences, missed intents, awkward phrasing). This is the highest-ROI 15-minute task from the whole week.
- **Seed your project memory.** In your voice AI repo, tell Claude: `Remember: I'm a PM at Theatro building voice AI for frontline workers on Bedrock. Agent responses must stay under 150 words.` That context will be live in every future session.
- **Add the filesystem MCP server** pointing at a folder with recent transcripts, then ask Claude to read, summarize, and flag issues — without pasting a single line yourself.
