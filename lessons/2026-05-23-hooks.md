# Hooks
_Day 7 — 2026-05-23_

> **TL;DR:** Hooks let you run a shell command automatically before or after Claude touches anything — so you can log, validate, or block actions without watching every step.

## What it is
Hooks are shell commands you configure in `settings.json` that fire at specific moments. Three types: `PreToolUse` (fires before a tool call), `PostToolUse` (fires after), and `Stop` (fires when Claude finishes responding). You pick which tool to target, or leave the matcher blank to catch everything.

## Why a PM building voice AI / agents should care
When you're iterating on voice agent prompts or transcript scripts, hooks give you a silent audit trail — every file Claude touches gets logged, which is handy for stakeholder reviews or rollbacks. A `Stop` hook can auto-run a smoke test after every session so you never hand off a broken agent flow.

## Try it in 60 seconds
Add this to `.claude/settings.json` to log every time Claude finishes:

```json
{
  "hooks": {
    "Stop": [
      {
        "matcher": "",
        "hooks": [
          { "type": "command", "command": "echo 'Session ended' >> claude-log.txt" }
        ]
      }
    ]
  }
}
```

## Walk-through
1. Open `.claude/settings.json` (create it if it doesn't exist).
2. Add a top-level `"hooks"` key.
3. Choose a hook type: `"PreToolUse"`, `"PostToolUse"`, or `"Stop"`.
4. Set `"matcher"` to a tool name (e.g. `"Bash"`) or `""` to match all tools.
5. Set `"command"` to any shell command — it runs automatically when the hook fires.

## Gotchas
- Test your command in the terminal first — a typo silently fails or can block Claude entirely.
- `PreToolUse` hooks can block a tool call: exit code `0` = allow, non-zero = block. Easy to misconfigure.
- Hooks are local to your machine; teammates won't get them unless they add the same config.
- The `Stop` hook fires even when Claude stops mid-task — not just on successful completion.

## Takeaway
One Stop hook in `settings.json` turns Claude into a self-testing agent — it's the cheapest safety net you can add.
