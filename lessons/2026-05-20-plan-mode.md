# Plan Mode
_Day 4 — 2026-05-20_

> **TL;DR:** Plan mode makes Claude propose what it's going to do before it does anything — so you can say "no, wait" instead of undoing changes.

## What it is
By default, Claude reads your prompt and starts executing immediately — editing files, running commands, etc. Plan mode (toggled with `/plan` or `Shift+Tab` twice) puts Claude into a read-only (no changes to files or commands) thinking phase first. It shows you a numbered plan and waits for your approval before touching anything.

## Why a PM building voice AI / agents should care
When you're iterating on an agent's prompt logic or conversation flow, a wrong edit can break things in subtle ways that are hard to trace back. Plan mode lets you review the *intent* before the *action* — you catch misunderstandings at the cheapest possible moment. It's also great when demoing to stakeholders: you can walk through what Claude plans to do without accidentally running anything.

## Try it in 60 seconds
In any Claude Code session, type:

```
Shift+Tab  (press twice to toggle into plan mode)
```

Then describe your task as usual. Claude will respond with a plan — no files touched. Hit Enter to approve and execute, or type corrections first.

## Walk-through
1. Open Claude Code in your project directory.
2. Press `Shift+Tab` twice — you'll see a `[plan]` indicator appear near the prompt.
3. Type your request, e.g. "Update the greeting message in the voice agent to mention the user's name."
4. Claude responds with a numbered list of what it would do (which files, what changes).
5. Read the plan, then type `yes` or just press Enter to let it proceed — or rephrase to correct it.

## Gotchas
- Plan mode is per-session — it resets when you exit Claude Code.
- Claude can still *read* files in plan mode; it just won't edit or run commands.
- If the plan looks right but execution still goes sideways, undo with `Ctrl+Z` or check `git diff`.
- Keyboard shortcut varies slightly by OS — if `Shift+Tab` doesn't work, type `/plan` instead.

## Takeaway
Think of plan mode as the "confirm before checkout" button — one extra step that prevents a lot of expensive mistakes.
