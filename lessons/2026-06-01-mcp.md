# MCP (Model Context Protocol)
_Day 16 — 2026-06-01_

> **TL;DR:** MCP is a standard plug that lets Claude reach into outside tools — databases, APIs, files — the same way you'd plug a USB device into a laptop.

## What it is
MCP stands for Model Context Protocol. It's an open standard (a shared agreement on how software talks to each other) that lets Claude connect to external data sources and services. Instead of Claude only knowing what you paste into the chat, MCP lets it pull live data from your calendar, codebase, Slack, or any tool that has an MCP server built.

## Why a PM building voice AI / agents should care
Your voice agents need data — shift schedules, product lookups, ticketing systems. MCP is how you give Claude access to that live data without writing custom glue code from scratch. If a vendor already published an MCP server for their tool (many have), you're one config line away from Claude reading or writing to it.

## Try it in 60 seconds
In your Claude Code session, type:

```
/mcp
```

This lists every MCP server currently connected. If it returns nothing, you haven't configured one yet — that's tomorrow's lesson.

## Walk-through
1. Think of MCP like a universal adapter: Claude is the device, your tool (Slack, GitHub, a database) is the wall socket, and the MCP server is the adapter in between.
2. An **MCP server** is a small program that speaks the MCP standard. Many are open-source and installable in minutes.
3. You add MCP servers to Claude Code via `settings.json` under the `"mcpServers"` key.
4. Once connected, Claude can read from or write to that tool using normal conversation — no extra commands.
5. Type `/mcp` at any time to see what's connected and whether each server is healthy.

## Gotchas
- MCP servers run locally on your machine or on a server you control — Claude doesn't magically reach the internet; something has to bridge it.
- Each MCP server has its own install and auth (authentication) steps — it's not plug-and-play out of the box.
- If you're using Claude at work via AWS Bedrock, MCP may need your IT team to approve or host the server.
- MCP is still evolving fast — a server that works today might need an update next month.

## Takeaway
MCP is the USB standard for AI tools — once you plug one in, Claude can work with live data instead of just what you copy-paste.
