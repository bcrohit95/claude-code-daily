# Skills
_Day 14 — 2026-05-30_

> **TL;DR:** Skills are pre-packaged playbooks that Claude loads on demand — invoke one slash command and a whole multi-step workflow runs automatically.

## What it is
A skill is a file that tells Claude how to handle a specific task: what steps to follow, what tools to use, and when to trigger automatically. Skills live in `.claude/skills/` (your project) or `~/.claude/skills/` (all projects). Built-in skills like `/code-review`, `/deep-research`, and `/run` ship with Claude Code and are ready to use today.

## Why a PM building voice AI / agents should care
You repeat the same workflows constantly — pull the latest voice agent transcripts, summarize them, file issues. A skill wraps that multi-step process into one command. You also use skills to let non-technical teammates trigger complex tasks without explaining anything to Claude each time.

## Try it in 60 seconds
In Claude Code, type:

```
/deep-research What are the top open-source TTS (text-to-speech) engines in 2026?
```

Claude fans out searches, cross-checks sources, and returns a cited report — no extra prompting needed.

## Walk-through
1. Open Claude Code in any project.
2. Type `/` to see the list of available skills (they appear alongside slash commands).
3. Pick one — try `/code-review` if you have a diff, or `/deep-research <question>` for research.
4. Claude loads the skill's instructions and executes the workflow step by step.
5. The result comes back fully formed — no back-and-forth required.

## Gotchas
- Skills and slash commands share the `/` prefix but are different things: slash commands run a single prompt template; skills run a full multi-step workflow.
- Built-in skills are always available; custom skills only load if the `.claude/skills/` folder exists in your project or home directory.
- Some skills (like `/deep-research`) spawn multiple sub-agents and can be slow — budget 1–2 minutes for deep tasks.
- Skills defined in your home directory apply everywhere; project-level skills only apply inside that repo.

## Takeaway
One slash command, zero re-explaining — that's the whole point of a skill.
