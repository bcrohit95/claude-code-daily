# Stop Hook
_Day 10 — 2026-05-26_

> **TL;DR:** A Stop hook runs automatically after Claude finishes its turn — perfect for catching broken tests or lint errors before you ever see the output.

## What it is
The Stop hook fires once, right when Claude stops responding. Unlike the PostToolUse hook (which fires after each tool call), this one fires at the end of the whole turn. You attach a shell script; if that script fails, Claude sees the failure and gets another shot at fixing it.

## Why a PM building voice AI / agents should care
When you're iterating on a voice agent prompt or flow with Claude's help, you want to know immediately if the change broke something — not after you've moved on. A Stop hook that runs your test suite means Claude self-corrects before handing back control, saving you a round trip.

## Try it in 60 seconds
Add this to your `.claude/settings.json`:

```json
{
  "hooks": {
    "Stop": [
      {
        "matcher": "",
        "hooks": [
          { "type": "command", "command": "npm test --silent 2>&1 | tail -5" }
        ]
      }
    ]
  }
}
```

## Walk-through
1. Open (or create) `.claude/settings.json` in your project root.
2. Add the `Stop` key inside `"hooks"` as shown above.
3. Replace `npm test --silent` with whatever check makes sense — `pytest`, `eslint .`, or even `echo "done"` to test the wiring.
4. Ask Claude to make a change. When it finishes, the hook runs automatically.
5. If the command exits with an error, Claude reads the output and tries to fix the problem — no manual re-prompting needed.

## Gotchas
- The hook command runs in your project directory, so relative paths work fine.
- If your test suite is slow (>30 s), Stop hooks will make every Claude turn feel sluggish — keep the command fast or scope it down.
- A hook that always fails (e.g., a broken script) will loop Claude endlessly; add a safety limit or test the command in your terminal first.
- This is a project-level setting in `.claude/settings.json`, so it only applies when Claude Code runs inside that folder.

## Takeaway
Stop hooks turn Claude from a code suggester into a self-checking collaborator — it doesn't hand back control until it knows things still work.
