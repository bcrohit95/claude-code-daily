# Tasks
_Day 19 — 2026-06-04_

> **TL;DR:** Tasks are Claude Code's built-in to-do list — when you ask it to do something with many steps, it tracks each step so you (and it) always know what's done, in-progress, and next.

## What it is
When Claude starts a multi-step job, it creates a task list — a live checklist visible in your session. Each item has a status: pending, in-progress, or completed. It updates the list as it works, so you can follow along in real time without reading walls of output.

## Why a PM building voice AI / agents should care
When you ask Claude to "set up a new voice agent flow," that's 8–10 steps under the hood. Tasks turn that opaque process into a visible checklist — you can see exactly where it stalled, what succeeded, and what's left. That visibility is also great for screensharing with engineers: instead of "Claude is doing something," you see a concrete progress list.

## Try it in 60 seconds
Just give Claude a multi-step request and watch the task list appear:

```
Build me a simple Node.js script that reads a CSV, 
filters rows where status = "active", and writes the 
result to a new file.
```

No special syntax needed — Claude creates the task list automatically.

## Walk-through
1. Type a multi-step request in Claude Code (like the example above).
2. Claude creates a task list at the start — one item per meaningful step.
3. Watch items flip from `pending` → `in-progress` → `completed` as it works.
4. If Claude gets stuck or asks a question, the checklist shows exactly where it paused.
5. When it finishes, all items are marked completed — you have a clear receipt of what was done.

## Gotchas
- Tasks only appear for multi-step jobs; a one-liner question won't generate a list.
- You can't manually edit the task list — Claude owns it; you just observe.
- If you interrupt mid-task and restart, Claude may re-create a fresh list rather than resuming the old one.
- Task lists live only for the session — they don't persist after you close the terminal.

## Takeaway
Tasks are Claude's way of thinking out loud — read them and you'll never wonder "what is it actually doing right now?"
