# The Bash Tool
_Day 21 — 2026-06-06_

> **TL;DR:** The Bash tool lets Claude run any terminal command on your machine — install packages, read logs, grep files — but it has a few sharp edges you'll hit if you don't know them.

## What it is
When Claude uses the Bash tool, it's literally running a shell command on your computer and reading the output. It's how Claude checks if a file exists, installs a dependency, or runs your test suite. Unlike Read/Edit/Write (which only touch files), Bash can do anything a terminal can.

## Why a PM building voice AI / agents should care
If you're prototyping an agent that processes call transcripts or checks an API, Claude can run those scripts for you mid-conversation — no switching tabs. You can ask "run the transcript parser on this sample file and show me the output" and Claude handles it. Less eng-dependency for quick experiments.

## Try it in 60 seconds
Just ask Claude to run something in plain English:

```
Can you list all .json files in this folder and show me how big they are?
```

Claude will call Bash with `find . -name "*.json" -ls` and show you the result directly.

## Walk-through
1. Start a Claude Code session in your project folder.
2. Ask Claude to run a command: "What Node version is installed?"
3. Claude calls Bash with `node --version` and shows the output.
4. Claude can chain commands too — ask "install the dependencies and check if tests pass."
5. You'll see a permission prompt before each command runs (unless you've set auto-accept).

## Gotchas
- **2-minute timeout by default.** Commands that hang or take too long will be killed. Long installs may need the `timeout` parameter increased.
- **Background jobs don't work as expected.** If you run something with `&` to send it to the background, Claude won't be able to read its output — the tool closes after the command returns.
- **No persistent shell state.** Each Bash call is independent. `cd /some/dir` in one call won't carry over to the next call — always use absolute paths.
- **You'll see a permission prompt** for each command unless you've configured auto-accept in settings. This is intentional — Bash is powerful and destructive commands are real.

## Takeaway
Bash tool = Claude's hands on your terminal; just remember each call is stateless, so absolute paths always beat `cd`.
